# بررسی نسخهٔ ۲۰۲۶/۱۰/۲۶

این گزارش مربوط به پنج تم سند، تنظیم یکپارچهٔ فونت و README راست‌به‌چپ است. منبع اصلی `assignment-template/` است و نسخهٔ `assignment-template-bundled/` از همان منابع تولید می‌شود.

## ساخت و ظاهر PDF

سه سند اصلی با latexmk و XeLaTeX در TeX Live 2025 ساخته شدند: `main.pdf` سه صفحه، `example.pdf` هفت صفحه و `code-demo.pdf` سه صفحهٔ A4 دارند. لاگ نهایی برای خطا، هشدار، ارجاع نامشخص، نویسهٔ گمشده و کادرهای بیرون‌زده بررسی می‌شود. تمام صفحات رندر می‌شوند؛ جهت فارسی و لاتین، جلد، فرمول‌ها، نمودارها، دیاگرام‌ها و شمارهٔ خط کد بازبینی می‌شوند. فونت‌ها در PDF جاسازی شده‌اند.

آزمون‌های مستقل `tools/verify_template.py` شامل هر پنج تم `warm`، `blue`، `green`، `plum` و `teal`، یک سند با اندازهٔ ۱۲ و خانواده‌های دیگر برای فونت لاتین و کد، و نمونهٔ کامل با `Latin Modern Math` هستند. حالت پیش‌فرض، فونت کلاسیک Computer Modern ریاضی است؛ گزینهٔ OpenType از unicode-math استفاده می‌کند. بردارها، ماتریس‌ها، عملگرها و اثبات در نمونهٔ کامل هم بررسی شدند.

انتخاب تم سند روی رنگ کدبلاک یا کادر خنثیِ کد درون‌خطی اثر ندارد. تعریف یک تنظیم پیش از `input{settings}` برای همان سند بر مقدار مشترک اولویت دارد.

## README در مرورگر

HTML از Markdown ساخته می‌شود و CSS و JavaScript را داخل خودش دارد. آزمون Edge بدون پنجره در عرض دسکتاپ ۱۴۴۰ و موبایل ۳۹۰ پیکسل، RTL بودن متن، LTR بودن کد، کارکرد پنج انتخاب تم، مقصد پیوندهای فهرست، وجود دکمهٔ کپی برای کدها و نبودن اسکرول افقی، خطای JavaScript و درخواست شبکه را بررسی می‌کند. تصویر دسکتاپ و موبایل نیز از نظر خوانایی بازبینی می‌شود. clipboard کاربر در آزمون خودکار تغییر نمی‌کند.

## بستهٔ همراه و انتقال

نسخهٔ bundled فونت‌های پیش‌فرض و مجوزها، محیط مجازی آماده، wheelهای آفلاین، پالت‌ها و ابزار بازسازی HTML را دارد. minted 3.8.0، fvextra 1.14.0 و latex2pydata 0.7.0 همراه منابع و مجوزها در texmf محلی قرار دارند. TeX Live، XeLaTeX/latexmk و Python پایه همچنان باید روی سیستم نصب باشند.

`tools/verify_bundle.py` ZIP را در مسیر تازهٔ دارای فاصله استخراج می‌کند، venv همراه را حذف و با `PIP_NO_INDEX=1` از wheelhouse بازسازی می‌کند و هر سه سند را می‌سازد. Scripts مربوط به Python سیستم از PATH این آزمون کنار گذاشته می‌شود. recorder باید استفاده از هر سه بستهٔ LaTeX محلی و هر سه خانوادهٔ فونت همراه را تأیید کند. صحت فرمان مشترک TeXstudio و build.cmd از طریق latexmkrc و کامپایل واقعی بررسی می‌شود؛ کلیک دستی روی دکمه‌های رابط گرافیکی TeXstudio خودکارسازی نشده است.

CRC و SHA-256 هر ZIP با فایل‌های پوشهٔ متناظر مقایسه می‌شود. منابع، تنظیمات، نمونه‌ها و README در دو نسخه یکسان‌اند. build، cache، __pycache__ و فایل موقت وارد ZIP نمی‌شوند؛ venv فقط در ZIP نسخهٔ bundled قرار می‌گیرد. پاک‌سازی عادی، محیط مجازی آماده را حفظ می‌کند.

## نگهداری گیت

منابع و ابزار نگهداری کامیت می‌شوند؛ bundled تولیدشده، خروجی‌ها، venv و referenceهای شخصی از گیت کنار گذاشته شده‌اند. اطلاعات دانشجو برای انتشار عمومی به مشخصات نمونه تبدیل شده است. تغییرهای تم و فونت، راهنما و بسته‌بندی در کامیت‌های متمرکز ثبت می‌شوند و قواعد ادامهٔ کار در AGENTS.md ریشهٔ مخزن قرار دارند.

گزارش‌های ماشینی و تصاویر در output/qa نگه داشته می‌شوند و جزو پوشهٔ قابل کپی نیستند. محتوای هر انتشار با manifest همان بسته مشخص می‌شود؛ این گزارش مسیر خصوصی نصب سیستم یا هش ثابتِ زودهنگام نگه نمی‌دارد.
